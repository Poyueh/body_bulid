資料匯入與匯出

登入後手機與電腦共用雲端紀錄；仍建議定期匯出 JSON 備份。

JSON 匯入採「相同日期覆蓋、其他資料保留」；InBody CSV 可匯入 InBody App 匯出的標準欄位（日期、體重、骨骼肌量、體脂率等）。
